# Evaluation Guidelines

This document describes how backend features will be evaluated in later phases.

- Product matching quality: unique match, ambiguous match, and no-match behaviour.
- Order workflow accuracy: draft creation, clarification, confirmation, and cancellation.
- Inventory safety: no negative stock and no duplicate order creation.
- Integration robustness: timeout, auth, rate-limit, and malformed-output handling.

Evaluation results will be reported only after actual runs are complete and will clearly separate mock-mode and real-provider results.
